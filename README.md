# منصة استبيانات أساب

منصة استبيانات كاملة (بدون تبعيات خارجية — Node المدمج + SQLite) بتصميم أساب.

## التشغيل
- انقر مرتين على `start.command` (أو من الطرفية: `node server.js`)
- الخادم يعمل على: http://localhost:4321

## الروابط
- الاستبيان الحالي: http://localhost:4321/s/design-partners
- لوحة الإدارة: http://localhost:4321/admin
- كلمة مرور الإدارة الافتراضية: `asap2026` (غيّرها من داخل اللوحة)

## المزايا
- **استبيانات متعددة**: كل استبيان له رابط `/s/<slug>` مستقل، وسجل ردود مستقل.
- **هوية مستقلة لكل استبيان**: شعار + لون أساسي + لون ثانوي + عنوان + نص تعريفي (تغييرها لا يؤثر على بقية الاستبيانات).
- **بناء الأسئلة**: إضافة/حذف/إعادة ترتيب. الأنواع:
  نص، فقرة، رقم، جوال، بريد إلكتروني، اختيار واحد، اختيارات متعددة (بحد أقصى)، مقياس رقمي، عنوان قسم.
- **تحديد "مطلوب" لكل سؤال**، وتحقق تلقائي من البريد.
- **تصدير Excel** لكل استبيان (ملف .xlsx حقيقي).
- **عرض الردود** في جدول داخل اللوحة.

## البيانات
- قاعدة البيانات: `data/surveys.db` (SQLite)
- الشعارات المرفوعة: `uploads/`

## إعادة تهيئة الاستبيان النموذجي
`node seed.js` (يعيد إنشاء استبيان شركاء التصميم بألوان وشعار أساب للتقنية القانونية).
